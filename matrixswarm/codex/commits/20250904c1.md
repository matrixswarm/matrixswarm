# Commit: Deployment UX Refactor — Auto-Refreshing & Hardened Mint

## Summary
This refactor brought our deployment pipeline in line with expectations:
- **Deployment dropdowns** now auto-refresh when vault changes.  
- **Allowlist IPs** flow cleanly through HTTPS and WSS agents.  
- **Minting logic hardened** against empty-list stomps.  
- Logs improved — operators see exactly what’s injected.

The whole cycle ran smooth as hell. 🪖

---

## ### Highlights

- **Allowlist Injection Fixed**
  - Added explicit support for `allowlist_ips` under `connection` in `CERT_INJECTION_MAP`.
  - Hardened `merge_config` to avoid overwriting valid data with empty lists.
  - HTTPS + WSS agents now both boot with the same `port` + `allowlist_ips` config.

- **HTTPS Allowlist Enforcement**
  - HTTPS agent upgraded to behave like WSS:
    - Logs explicit allowlist decisions (`allowed`, `blocked`, `no restriction`).
    - No silent passes anymore — operators see who’s let in.

- **Deployment Minting Hardened**
  - `node.setdefault("config", {})` ensures every agent has a safe config block.
  - Ports and allowlist IPs are logged during mint:
    ```
    [DEPLOYMENT MINT] Injecting port=8765 for agent 'websocket-relay'
    [DEPLOYMENT MINT] Injecting allowlist_ips=['199.193.85.57'] for agent 'websocket-relay'
    ```
  - Non-perimeter agents skip quietly, avoiding crashes.

- **PhoenixControlPanel UX Refactor**
  - Deployment dropdown auto-refreshes on `vault.update` events.
  - No need to reopen control panel after add/delete.
  - Operator sees the new deployment list immediately.

- **Directive Manager Sync**
  - `delete_deployed` and new deployments now emit `vault.update`.
  - Control Panel listens, keeping dropdown state in sync with vault data.

---

## Verification
- Deployed HTTPS/WSS agents boot with allowlist enforcement active.  
- Mint logs show both ports and IPs injected.  
- Deployments added/removed update the dropdown in PhoenixControlPanel instantly.  
- Invalid IPs rejected at dialog level, clean error message to user.  
- Guardians and non-perimeter agents mint without config errors.
